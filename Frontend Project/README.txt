Topic: Flower Shop - AJ Floral 🌸

Project Description:
AJ Floral is a simple website designed to showcase a flower shop’s products and services. 
The site features:

    Home Page: Introduces the shop and highlights popular flowers.
    Flowers Page: Displays all available flowers in a grid layout.
    Order Page: Allows customers to place orders online.
    About Page: Shares the shop’s background and story.
    Contact Page: Provides ways for customers to reach us.

How to Test or Use the Project:

    Download or extract the project folder (AJ Floral) from the ZIP file.
    Open index.html in any modern web browser.
    Use the navigation bar or hamburger menu (on small screens) to move between pages.
    On the Order Page, you can test the order form by entering details.
    The website is fully responsive — resize the browser window to see how it adapts for mobile screens.
