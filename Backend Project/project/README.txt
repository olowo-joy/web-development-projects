# Jokecast Journal 🎉

## 📌 Topic
**Jokecast Journal** is a fun, interactive web project that combines:
- 🌤 **Weather forecasts** (powered by Open‑Meteo + Nominatim, no API keys required)
- 📰 **Top space headlines** (powered by Spaceflight News API, free and public)
- 😂 **Random jokes** (from the Official Joke API)

It’s designed to be colorful, emoji‑friendly, and easy to use.

---

## 📄 Pages

### 🏠 Home (`home.html`)
- Quick weather lookup by city
- Preview of top headlines
- Daily joke with refresh button

### 📰 News (`news.html`)
- Displays the latest space‑related headlines
- Each article shows title, summary, date, and link to read more

### 🌤 Weather (`weather.html`)
- Full weather search by city
- Shows location, condition (with emoji), temperature, and wind speed

---

## ▶️ How to Run the Project
1. **Download or clone** the project folder.
2. Make sure the following files are present:
   - `home.html`, `news.html`, `weather.html`
   - `style.css`
   - `app.js`
   - `images/logo.png` (your logo file)
3. Open any of the HTML files (e.g. `home.html`) in a web browser:
   - Double‑click the file, or
   - Right‑click → “Open With” → choose your browser
4. The pages will load data directly from the public APIs — no server setup required.

---

## 🚀 Notes
- Ensure your `images/logo.png` path is correct so the logo displays.
- Requires an internet connection to fetch weather, news, and jokes.
- Works best in modern browsers (Chrome, Edge, Firefox).
